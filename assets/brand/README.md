# Brand assets

原本の PNG / SVG はなく、提供された `repository-overview.jpg`（1536×1024 JPEG）から切り出しています。JPEG 由来のため、拡大するとブロックノイズが出ます。512px 級のアバターには向きません。再色・マスク・透明化はしていません。角の余りは、切り出し元のカード背景色 (RGB 246, 250, 253) で正方形に揃えています。

- [アイコン](https://myon-bioinformatics.github.io/OneLaunchNumerousModules/icon.png): 切り出し箱 `(18, 14, 376, 346)`（右・下は含まない、358×332）。背景で 358×358 にパディング。
- favicon（CaChereCyCle の `OneLaunchNumerousModules.favicon`）: 切り出し箱 `(433, 188, 567, 315)`（134×127）。背景で 134×134 にパディング。
- [概念図](repository-concept.jpg): 切り出し箱 `(0, 408, 1536, 1024)`。アイコン／favicon のキャプション行より下、見出し「概念図」を含む。JPEG quality=95, subsampling=0 で再保存（ソースも JPEG）。
- [提供画像（原本）](repository-overview.jpg): アイコン・favicon・概念図が同居していた見本ボード。README の表示には使いません。

GitHub Pages の利用ガイドは、アイコンと favicon を CaChereCyCle から受け取ります（`guide_brand`）。リポジトリにコピーは置きません。
